CSA43 – INTERNET PROGRAMMING
CO-2 Assessment Tool 2: Design Task (20 marks)

WHAT TO DO
1. Extract this ZIP file.
2. Open index.html in a browser (Chrome recommended). No installation is needed.
3. Test the responsive navigation: resize the browser or use a phone-sized window, then click the ☰ menu.
4. Hover/focus on product cards and click Add to cart.
5. Resize the page to see the dashboard and blog layout adapt.
6. Click “Test JavaScript event”.
7. Read the notes in ASSIGNMENT_ANSWERS.txt for the written explanations for all five questions.

FILES
- index.html: page structure and sample content
- style.css: responsive navigation, product effects, dashboard Grid, mobile-first blog and accessibility styles
- script.js: menu toggle, cart updates and click event
- ASSIGNMENT_ANSWERS.txt: written answers and evaluation points

SUBMISSION CHECKLIST
- Replace the Name / Reg No. line in the written answers with your own details.
- Take screenshots of the website at desktop and mobile widths if your instructor requires them.
- Submit the HTML, CSS and JavaScript files together. Keep the three code files in the same folder.
- Do not claim that screenshots or testing were done unless you have actually done them.
