# CanvasPulse - Artwork Exhibition & Sentiment Rating Portal

## Aim
To build an art exhibition and review platform ('CanvasPulse') where painting owners pay for display duration packages, visitors rate artworks (1–5 stars) with comments, and sentiment summaries are dynamically computed.

## Procedure
1. Create a Featured Exhibition Viewer calculating average star ratings and categorizing Positive (≥4★) vs Critical (<4★) sentiment feedback.
2. Implement an Artist/Owner Submission form with display duration package pricing (7 Days / 15 Days / 30 Days).
3. Provide an Admin Exhibition Switcher displaying prior painting sentiment analytics before rotating displays.

## How to Run
Open `index.html` directly in any web browser.
