# FlavorVault - Digital Recipe Book & Meal Planner

## Aim
To design and develop a digital recipe book platform ('FlavorVault') enabling users to filter recipes by cuisine/diet, scale ingredient quantities by serving size, submit new recipes, and build weekly shopping lists.

## Procedure
1. Create a responsive recipe catalog with cuisine and dietary filters (Breakfast, Main Course, Dessert, Vegetarian).
2. Implement dynamic serving-size ingredient scaling, recipe ratings/comments, and a one-click shopping list builder.
3. Build a user recipe submission form to add new culinary creations to the live collection.

## How to Run
Open `index.html` directly in any web browser.
