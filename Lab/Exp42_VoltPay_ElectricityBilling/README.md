# VoltPay - Online Electricity Bill Calculator & Payment Portal

## Aim
To build an online electricity billing portal ('VoltPay') implementing progressive slab tariff calculations for Domestic and Commercial connections, overdue late-fee computation (₹10/day), and digital receipt generation.

## Procedure
1. Implement the exact statutory slab engine: Domestic (0–100 @ ₹1, 101–200 @ ₹2.50, 201–500 @ ₹4, >500 @ ₹6) and Commercial (0–100 @ ₹2, 101–200 @ ₹4.50, 201–500 @ ₹6, >500 @ ₹7).
2. Add overdue penalty calculation (₹10 per late day past due date) and multi-mode payment checkout with printable receipt.
3. Provide an Admin Billing Cycle & Slab Monitor view.

## How to Run
Open `index.html` directly in any web browser.
