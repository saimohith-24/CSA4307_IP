# BlossomGifts - Floral & Gift E-Commerce

## Aim
To develop an online flower and gift store ('BlossomGifts') featuring category/occasion filtering, customizable delivery schedules, shopping cart management, and admin inventory control.

## Procedure
1. Structure a storefront with occasion filters (Birthday, Anniversary, Corporate) and interactive product cards.
2. Implement a live shopping cart allowing quantity adjustments, item removal, and custom gift note/delivery date selection.
3. Build an Admin Inventory drawer to add new bouquets/gifts, update prices, and view customer checkout summaries.

## How to Run
Open `index.html` directly in any web browser.
