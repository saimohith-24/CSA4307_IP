# RoadAssist - On-Road Vehicle Breakdown Assistance

## Aim
To create an emergency roadside assistance web application ('RoadAssist') enabling stranded drivers to locate licensed nearby mechanics, view geo-coordinates, request dispatch, and admins to approve workshops.

## Procedure
1. Display verified roadside mechanics filtered by location and vehicle issue (Engine, Tyre, Battery, Towing).
2. Allow drivers to send an SOS breakdown request with live geo-coordinates.
3. Provide a Mechanic Registration form and an Admin Workshop Approval toggle.

## How to Run
Open `index.html` directly in any web browser.
