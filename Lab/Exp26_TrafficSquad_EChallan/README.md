# Traffic Squad - Online E-Challan & Penalty System

## Aim
To build a traffic violation management system ('Traffic Squad') allowing police officers to issue digital FIR/challans with violation proof and vehicle owners to view and pay penalties online.

## Procedure
1. Create a Vehicle Owner Challan Lookup by Registration Number with one-click online fine settlement.
2. Build a Traffic Police Enforcement Desk to log new violations (Signal Jump, No Helmet, Overspeeding) and calculate statutory fines.
3. Include an Admin Daily Revenue & Violation Report summary.

## How to Run
Open `index.html` directly in any web browser.
