# SmartBusPass - Student & Commuter QR Bus Pass Portal

## Aim
To design an online bus pass management system ('SmartBusPass') supporting free government student passes, paid commuter passes, eWallet renewals, Admin QR issuance, and Conductor pass verification.

## Procedure
1. Implement a Bus Pass Application form distinguishing Government School Students (₹0) and Route Commuters (₹350/month).
2. Build an Admin Approval panel to generate QR pass codes and manage bus route schedules.
3. Add a Conductor QR Verification scanner to validate active student/commuter passes.

## How to Run
Open `index.html` directly in any web browser.
