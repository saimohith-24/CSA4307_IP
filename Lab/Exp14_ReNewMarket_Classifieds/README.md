# ReNewMarket - Second-Hand Marketplace

## Aim
To build a sustainable pre-owned goods marketplace ('ReNewMarket') with category filters, seller listing creation, price negotiation offers, and admin logistics tracking.

## Procedure
1. Create a responsive marketplace grid showcasing pre-loved Electronics, Furniture, and Books.
2. Implement a 'Sell Item' modal/form allowing users to publish new second-hand listings.
3. Add buyer negotiation ('Make Offer') and direct purchase workflows.
4. Include an Admin Logistics panel to update order statuses (Pending -> Shipped -> Delivered).

## How to Run
Open `index.html` directly in any web browser.
