# AgriMart - Farmer-to-Buyer Agricultural Store

## Aim
To build an agricultural e-commerce platform ('AgriMart') connecting farmers selling seeds, fertilizers, and produce directly with buyers featuring wallet checkout and farmer inventory updates.

## Procedure
1. Create dual views for Public Buyers (Category Filter, Cart, eWallet Checkout) and Farmers (Add Produce/Supplies, Sales Tracker).
2. Implement real-time stock and wallet balance deductions upon order placement.
3. Allow farmers to update shipment statuses for incoming buyer orders.

## How to Run
Open `index.html` directly in any web browser.
