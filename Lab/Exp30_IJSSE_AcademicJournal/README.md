# IJSSE - International Journal of Scientific & Social Excellence

## Aim
To build an academic journal publishing portal ('IJSSE') displaying ISSN credentials, current/archived peer-reviewed articles, author manuscript submission, and reviewer/editor workflow panels.

## Procedure
1. Build structured navigation covering Journal Overview (Print ISSN 2395-1443, Online ISSN 2395-1451), Current Issue Articles, Call for Papers/Manuscript Submission, and Editorial Board.
2. Implement interactive manuscript submission for Authors and peer-review status updates for Reviewers/Editors.

## How to Run
Open `index.html` directly in any web browser.
