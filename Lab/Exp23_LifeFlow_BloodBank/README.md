# LifeFlow - Blood Bank & Donor Management System

## Aim
To build a blood management information system ('LifeFlow') enabling users to register as blood donors, search donors and hospital blood stocks by blood group, and hospitals to update unit availability.

## Procedure
1. Create a Blood Group search filter (A+, B+, O+, O-, AB+, etc.) across registered donors and hospital blood banks.
2. Implement a Donor Registration form to add voluntary donors with city and availability status.
3. Build a Hospital Blood Bank Console to update real-time blood unit stock counts.

## How to Run
Open `index.html` directly in any web browser.
