# EduConnect - Interactive Online Teaching & LMS Portal

## Aim
To build an e-learning management system ('EduConnect') featuring course catalog enrollment, downloadable study modules, interactive quizzes, and instructor course creation.

## Procedure
1. Create Student Course Catalog with subject allocation and interactive quiz assessment.
2. Build an Instructor Dashboard allowing teachers to publish new courses and study notes.

## How to Run
Open `index.html` directly in any web browser.
