# ArtistryHub - Artist Portfolio & Print Store

## Aim
To create a visually curated artist portfolio website ('ArtistryHub') showcasing Emily Harris's artwork gallery, biography milestones, exhibition news, newsletter signup, and limited-edition print store.

## Procedure
1. Structure sections for Hero Showcase, Interactive Artwork Gallery with medium filters, Artist Biography, and Print Shop.
2. Implement lightbox/detail modal inspection for individual artworks and newsletter subscription feedback.

## How to Run
Open `index.html` directly in any web browser.
