# VetCare - Livestock Telemedicine & Disease Portal

## Aim
To create a veterinary telemedicine system ('VetCare') where farmers submit animal symptom reports, subscribe to Govt/Private vets, and veterinarians prescribe cures while tracking regional disease trends.

## Procedure
1. Build a Farmer Consultation submission form supporting animal species, symptoms, and clinic tier (Free Govt CVH vs Private Clinic).
2. Create a Veterinarian Dashboard to review farmer symptom cases and post prescriptions.
3. Display a Regional Disease Surveillance summary aggregating reported cases.

## How to Run
Open `index.html` directly in any web browser.
