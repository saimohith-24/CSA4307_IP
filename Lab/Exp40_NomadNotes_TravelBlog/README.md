# NomadNotes - Interactive Travel Blog & Destination Map

## Aim
To build a travel blog platform ('NomadNotes') featuring destination-filtered travel stories, interactive destination map pins, packing checklist resources, and reader comment threads.

## Procedure
1. Create a region/destination filter and interactive destination pin selector linking directly to full travelogues.
2. Implement live reader comments on travel articles and a Packing & Travel Resources drawer.

## How to Run
Open `index.html` directly in any web browser.
