# Wanderlust Travels - Holiday Packages & Accommodation Portal

## Aim
To design an online travel agency platform ('Wanderlust Travels') enabling tourists to explore destination routes, local cuisine, and hostels/hotels, book packages, and admins to publish new itineraries.

## Procedure
1. Create destination cards featuring route itineraries, famous local food specialties, and hostel/hotel tariffs.
2. Implement traveler package booking with guest count and instant itinerary confirmation.
3. Build an Admin Tourism Manager to add new destinations and inspect customer bookings.

## How to Run
Open `index.html` directly in any web browser.
