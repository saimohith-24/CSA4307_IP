# DevSphere 2026 - Tech Conference & Speaker Schedule Page

## Aim
To design a clean, sectioned event landing page featuring keynote speaker profiles, event venue and purpose, session schedule timeline, and an interactive attendee registration form.

## Procedure
1. Design distinct color-coded sections for Event Header, Purpose & Target Audience, Speaker Lineup, Schedule Table, and Registration.
2. Implement interactive ticket registration with instant confirmation badge generation.

## How to Run
Open `index.html` directly in any web browser.
