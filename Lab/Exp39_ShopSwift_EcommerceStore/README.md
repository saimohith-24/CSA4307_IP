# ShopSwift - Product Catalog & Checkout Portal

## Aim
To develop an e-commerce store ('ShopSwift') with category/price filtering, product size/color variant selection, dynamic shopping cart quantity controls, and order confirmation summaries.

## Procedure
1. Create a clean product catalog supporting category filters and price sorting.
2. Implement interactive shopping cart quantity increments, removals, and itemized checkout summary.

## How to Run
Open `index.html` directly in any web browser.
