# Ram Infotech - Laptop Sales, Rentals & Service Portal

## Aim
To develop an IT retail and repair web platform ('Ram Infotech') supporting laptop catalog browsing, repair service ticket booking, laptop rental agreements, and admin stock management.

## Procedure
1. Build a Laptop Storefront displaying model configurations, stock counts, and instant purchase/rental options.
2. Implement a Service Center booking form allowing customers to log hardware issues and track repair status.
3. Add an Admin Stock & Service Queue manager to update repair progress and add new laptop models.

## How to Run
Open `index.html` directly in any web browser.
