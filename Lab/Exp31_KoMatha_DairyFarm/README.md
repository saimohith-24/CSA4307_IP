# Ko-Matha Dairy Farm - Smart Dairy & Stock Portal

## Aim
To design and develop a smart dairy farm web application ('Ko-Matha Dairy Farm') showcasing A1 cow milk products, online delivery orders, vendor/cattle records, and daily/monthly/yearly stock reports.

## Procedure
1. Create a responsive dairy storefront featuring fresh milk, curd, cova-sweet, butter, and ghee with online delivery scheduling.
2. Build an Admin & Stock Ledger module to record daily milk procurement, vendor/cow details, and automated daily/monthly/yearly stock reports.
3. Implement customer order placement with live stock deduction and order history tracking.

## How to Run
Open `index.html` directly in any web browser.
