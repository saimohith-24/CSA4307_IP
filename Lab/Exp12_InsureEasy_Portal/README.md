# InsureEasy - Insurance Management System

## Aim
To build an insurance management portal ('InsureEasy') supporting policy comparison, customer policy management, agent approval workflows, and automated renewal SMS alert logs.

## Procedure
1. Design a multi-role dashboard switching cleanly between Customer Policy Portal, Agent Workspace, and Admin Approval Panel.
2. Create an interactive policy comparison matrix (Health, Auto, Term Life) with instant premium calculation.
3. Implement Agent registration/approval by Admin and customer policy issuance.
4. Add an automated renewal due-date tracker with one-click SMS reminder simulation.

## How to Run
Open `index.html` directly in any web browser.
