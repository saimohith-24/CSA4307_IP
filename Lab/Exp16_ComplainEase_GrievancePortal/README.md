# ComplainEase - Civic Grievance & Resolution Portal

## Aim
To implement a civic complaint tracking system ('ComplainEase') allowing citizens to lodge grievances with geo-coordinates, officers to update resolution proofs, and admins to manage accounts.

## Procedure
1. Create a 3-tier grievance portal: Citizen Submission, Field Officer Resolution Desk, and Admin Control.
2. Capture complaint category, location coordinates, and description with instant ticket generation.
3. Allow officers to update status (Open -> In Progress -> Resolved) with work proof remarks.

## How to Run
Open `index.html` directly in any web browser.
