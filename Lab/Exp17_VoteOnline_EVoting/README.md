# VoteOnline - Secure Electronic Voting Portal

## Aim
To develop an e-voting web application ('VoteOnline') featuring Voter ID authentication, OTP verification simulation, one-person-one-vote ballot casting, and live election tallying.

## Procedure
1. Implement a 2-step voter verification screen (Voter ID check + simulated 4-digit OTP).
2. Prevent duplicate voting by locking each Voter ID once a ballot is cast.
3. Provide an Admin Election Control panel to add candidates and view real-time bar-chart results.

## How to Run
Open `index.html` directly in any web browser.
