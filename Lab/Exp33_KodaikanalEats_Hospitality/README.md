# KodaikanalEats & Resort Suites - Dining & Stay Booking

## Aim
To build an integrated hospitality platform ('KodaikanalEats') combining Kodaikanal restaurant table reservations with seasonal/non-seasonal suite bookings and room-attendant availability.

## Procedure
1. Create a Kodaikanal Restaurant Explorer with cuisine filters and instant table reservation.
2. Build a Resort Suite Booking calculator adjusting tariffs dynamically for Seasonal vs Non-Seasonal dates.
3. Include an Admin Room & Attendant Availability dashboard.

## How to Run
Open `index.html` directly in any web browser.
