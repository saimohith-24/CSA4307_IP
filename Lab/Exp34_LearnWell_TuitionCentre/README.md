# LearnWell Tuition Centre - Courses, Fees & Announcements

## Aim
To design a coaching institute web portal ('LearnWell Tuition Centre') featuring noticeboard announcements, online/offline subject enrollment, student fee reports, and maintenance requests.

## Procedure
1. Display an Announcements board alongside Subject Offerings with duration, fees, and Online/Offline batch modes.
2. Implement Student Enrollment and monthly fee status tracking.
3. Provide a Student/Parent Maintenance & Assistance Request desk.

## How to Run
Open `index.html` directly in any web browser.
