# RentRide - Self-Drive & Fleet Rental Portal

## Aim
To design a vehicle rental web platform ('RentRide') allowing users to filter cars/SUVs by category and duration, calculate rental tariffs, book vehicles, and manage fleet approvals via Admin.

## Procedure
1. Create a fleet showcase with filters for Vehicle Type (Hatchback, Sedan, SUV) and dynamic rental cost calculation based on days.
2. Implement customer booking forms with instant reservation confirmation.
3. Build an Admin Fleet & Booking Manager to add new vehicles and approve/reject customer reservations.

## How to Run
Open `index.html` directly in any web browser.
