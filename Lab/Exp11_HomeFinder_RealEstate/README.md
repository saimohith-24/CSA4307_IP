# Home Finder - Real Estate Portal

## Aim
To design and develop an online real estate platform ('Home Finder') allowing buyers to search, filter, save search criteria, view property details, and locate properties on an interactive map view.

## Procedure
1. Create the HTML5 semantic layout with navigation tabs for Buyer Login/Dashboard, Property Search, Saved Criteria, and Agent Directory.
2. Style the interface using clean CSS3 Grid/Flexbox cards, budget sliders, and responsive badges.
3. Implement JavaScript state management using localStorage for buyer authentication, saved search filters, and property visit logs.
4. Build dynamic search filtering (location, budget, property type) and an interactive map pin preview.
5. Test booking property viewings and verifying saved search criteria persistence.

## How to Run
Open `index.html` directly in any web browser.
