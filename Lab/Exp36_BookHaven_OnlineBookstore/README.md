# BookHaven - Online Bookstore & Catalog

## Aim
To design a clean online bookstore ('BookHaven') featuring genre filters, bestseller highlights, shopping cart management, and static informational pages (About, FAQs, Privacy Policy).

## Procedure
1. Create a multi-page navigation bar covering Catalog, Cart/Checkout, About Us, FAQs, and Privacy Policy.
2. Implement genre filtering and search across Fiction, Non-Fiction, and Academic titles with live cart totals.

## How to Run
Open `index.html` directly in any web browser.
