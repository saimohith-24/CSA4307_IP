# PlacePrep - Online Campus Placement Examination Portal

## Aim
To develop an online placement test system ('PlacePrep') where candidates take timed aptitude/coding MCQs, receive automated scorecards and rankings, apply for re-evaluation, and admins manage exam questions.

## Procedure
1. Build a Candidate Exam Interface with instant automated MCQ evaluation, pass/fail threshold check, and downloadable scorecard.
2. Implement a Merit Leaderboard ranking passed candidates and a Re-evaluation request button.
3. Add an Admin Question Bank & Schedule publisher.

## How to Run
Open `index.html` directly in any web browser.
