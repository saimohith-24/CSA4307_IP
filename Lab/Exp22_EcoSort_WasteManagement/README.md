# EcoSort - Smart Solid Waste Management System

## Aim
To develop a smart solid waste management portal ('EcoSort') with three role dashboards: Citizens (bin overflow complaints), Drivers (optimized route & load updates), and Admin (bin registry & analytics).

## Procedure
1. Create three switchable interfaces for Citizens, Collection Truck Drivers, and Municipal Admins.
2. Implement smart bin fill-level tracking (Dry/Wet/E-Waste) and automated route priority generation.
3. Allow citizens to lodge missed-pickup complaints and drivers to log truck load completion.

## How to Run
Open `index.html` directly in any web browser.
