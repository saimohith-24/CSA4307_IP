# HireLink - Online Job & Recruitment Portal

## Aim
To design and develop an online job recruitment portal ('HireLink') enabling applicants to search/filter job vacancies, apply with resumes, and recruiters/admins to post vacancies and shortlist candidates.

## Procedure
1. Create a responsive recruitment interface with Applicant Search, Recruiter Vacancy Publisher, and Admin Approval tabs.
2. Implement keyword, location, and role-category filters alongside resume/profile privacy controls.
3. Build recruiter workflows to post new vacancies and inspect applied candidate lists.

## How to Run
Open `index.html` directly in any web browser.
