# EasyToll - Smart Highway Toll & QR Pass Portal

## Aim
To create an online toll fee management system ('EasyToll') enabling drivers to recharge eWallets, buy eTickets, apply for monthly toll passes with QR codes, and verify passes at toll plazas.

## Procedure
1. Design a 3-role workflow: Vehicle Owner (eWallet & Pass Application), Toll Booth Operator (QR Verification), and Admin (Pass Approval).
2. Implement dynamic eWallet top-ups and instant toll ticket deductions.
3. Generate unique Toll Pass IDs and visual QR code badges upon Admin approval.
4. Build a Toll Gate scanner simulator to verify pass validity in real time.

## How to Run
Open `index.html` directly in any web browser.
