# Gourmet Haven - Fine Dining Menu & Table Reservation

## Aim
To design a fine-dining restaurant web application ('Gourmet Haven') featuring categorized culinary menus, special seasonal offers, customer testimonials, and an interactive table reservation system.

## Procedure
1. Build a categorized menu viewer (Appetizers, Main Course, Desserts) with ingredient notes and pricing.
2. Implement an online Table Reservation booking form with date, time slot, and party size.
3. Include Chef Philosophy, Seasonal Offers, and Guest Testimonials sections.

## How to Run
Open `index.html` directly in any web browser.
